# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — semver.

## 1.0.0 — 31.10.2026

Первый публичный релиз в составе репозитория `dsh-bond-plugins`.

### Добавлено

- Подсветка встроенного чипа «N subagents» в шапке беседы акцентным цветом темы,
  пока работает хотя бы один субагент; в простое чип возвращается к родному
  приглушённому цвету.
- Мягкое пульсирующее кольцо вокруг чипа (по атрибуту
  `html[data-dsw-subind="running"]`) и вокруг точки активности
  (`_activitySlot::after`); кольцо на атрибуте не зависит от хешированных
  классов хоста.
- Настройки в `localStorage["dsh.subagentIndicator"]`: `mode`
  (`glow` / `pill` / `both`), `intensity` (`subtle` / `normal` / `strong`),
  `color` (`green` / `yellow` / `blue`) с валидацией каждого поля и откатом к
  умолчанию при мусоре.
- Режим `pill`: отдельная пилюля со счётчиком рядом с чипом, `role="status"`,
  русское склонение («1 субагент работает» / «2 субагентов работают»), мигающая
  точка; рисуется только при `running > 0`.
- Публикация состояния на `<html>` для CSS и диагностики:
  `data-dsw-subind` (`running`/`idle`), `data-dsw-subind-count`,
  `data-dsw-subind-total`, `data-dsw-subind-color`; переменные
  `--dsw-subind-color`, `--dsw-subind-pulse-duration`, `-scale`, `-opacity`.
- Поддержка `prefers-reduced-motion: reduce`: цвет и статичное кольцо остаются,
  анимации (кольца и мигание точки) выключаются.
- Только токены темы `--dsw-alias-*` и `--dsw-radius-sm` — ни одного hex/rgb/hsl;
  палитра ограничена опубликованными алиасами (`state-success`,
  `state-warn`, `brand`).
- 19 сторожевых тестов собственного мини-harness (`node test/run-tests.mjs`),
  включая проверку «каждый алиас темы опубликован» и «нет хардкод-цветов».
- Вспомогательные скрипты `test/build-preview.mjs` (статичное превью
  `preview.html`) и `test/dump-css.mjs` (построчный дамп стилей с проверкой
  баланса скобок).

### Ограничения релиза

- Селекторы опираются на разметку встроенного чипа (`aria-haspopup="tree"`,
  подстроки классов CSS-модуля): при смене разметки подсветка деградирует до
  атрибутного кольца.
- Настройки читаются при монтировании: после правки `localStorage` нужна
  перезагрузка плагинов ⟳.
- Режимы `pill` и `both` в этой сборке визуально совпадают (стили чипа
  применяются всегда, `mode` управляет только пилюлей).
- Host-части нет: серверных маршрутов, инструментов и хранения на диске нет.
