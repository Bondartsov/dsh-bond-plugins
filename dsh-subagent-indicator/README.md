# dsh-subagent-indicator — заметный индикатор субагентов

`@local/dsh-subagent-indicator` подсвечивает встроенный чип **«N subagents»** в
шапке беседы, пока работают субагенты: акцентный цвет темы и мягкое пульсирующее
кольцо. Когда все простаивают, чип остаётся приглушённым, как в оригинале, без
анимации. Собственного чипа плагин не рисует — он перекрашивает существующий,
поэтому геометрия шапки не меняется.

## 1. Что это и какую задачу решает

Работающий субагент в DSH виден только по точке в чипе шапки и по растущему
счётчику: на белом фоне светлой темы это легко пропустить, а ждать завершения
субагента приходится часто. Плагин делает состояние заметным, не добавляя нового
элемента управления:

- **чип получает акцент** (`--dsw-subind-color`) — по умолчанию зелёный, можно
  переключить на жёлтый или синий;
- **вокруг чипа и вокруг точки активности идёт мягкое кольцо** с настраиваемой
  интенсивностью;
- по желанию — **отдельная пилюля со счётчиком** «● 2» рядом с чипом;
- при `prefers-reduced-motion: reduce` цвет остаётся (состояние видно), анимация
  исчезает.

## 2. Требования

- **DeepSeek Harness 2.x**, десктопная сборка (Electron). Нужны встроенный
  счётчик субагентов в шапке (`@deepseek-ai/dsh-client-ui-subagent`) и слот
  `conversation.session.header.actions`.
- Собственных зависимостей нет — только `react` хоста.
- Node.js 20+ и pnpm 9+ — только для установки из репозитория.
- Плагин **чисто клиентский**: Host-половина пустая, серверных маршрутов и
  инструментов нет.

## 3. Установка из репозитория `dsh-bond-plugins`

```powershell
git clone https://github.com/<ваш-логин>/dsh-bond-plugins.git
cd dsh-bond-plugins
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1
```

Только этот плагин:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Only "@local/dsh-subagent-indicator"
```

План без изменений: `install.ps1 -WhatIf`. Нестандартный профиль:
`-ProfileDir "<путь-к-профилю>"`.

Скрипт снимает резервную копию `package.json` и `cordis.patch.yml` профиля в
`<профиль>\backups\<ДД.ММ.ГГГГ>-<ЧЧММСС>`, добавляет пакет в `dependencies` как
`link:`, добавляет его в `dsh.profile.bundles` и запускает `pnpm install`.

После установки достаточно **перезагрузки плагинов ⟳**: Host-части у плагина нет,
клиентский бандл пересобирается при перезагрузке страницы. Перезапуск DSH нужен,
только если ⟳ недоступна.

## 4. Как пользоваться

Ничего нажимать не нужно — индикатор работает сам.

1. Откройте сессию, в которой работают субагенты (например, запустили несколько
   `subagent` или `workflow`).
2. Чип **«N subagents»** в шапке беседы (кнопка с раскрывающимся деревом) в это
   время окрашен в акцент и окружён пульсирующим кольцом; вокруг точки
   активности — расширяющееся кольцо.
3. Когда все субагенты простаивают, кольцо исчезает, чип возвращается к родному
   приглушённому цвету. Ховер и фокус работают как раньше.
4. В режиме `pill`/`both` рядом с чипом появляется пилюля **«● N»** — только пока
   хотя бы один субагент работает; в простое её нет вовсе.
5. Состояние можно посмотреть в DevTools (диагностика, не для повседневной
   работы): на `<html>` выставлены `data-dsw-subind="running|idle"`,
   `data-dsw-subind-count` (работающих), `data-dsw-subind-total` (всего в
   каталоге), `data-dsw-subind-color` (выбранный цвет), а в CSS — переменные
   `--dsw-subind-color`, `--dsw-subind-pulse-duration`, `--dsw-subind-pulse-scale`,
   `--dsw-subind-pulse-opacity`.

## 5. Настройка

Единственный источник настроек — `localStorage` ключ **`dsh.subagentIndicator`**:

```json
{ "mode": "glow", "intensity": "normal", "color": "green" }
```

| Поле | Допустимые значения | По умолчанию | Что даёт |
|---|---|---|---|
| `mode` | `glow` | ✅ | только подсветка и пульсация встроенного чипа; в DOM не добавляется ни одного узла |
| | `pill` | | подсветка чипа + отдельная пилюля со счётчиком |
| | `both` | | то же, что `pill` (в текущей сборке стили применяются всегда, поэтому `pill` и `both` визуально совпадают) |
| `intensity` | `subtle` | | 2800 мс, масштаб кольца ×1.8, прозрачность 45 % — медленно и бледно |
| | `normal` | ✅ | 2000 мс, ×2.2, 55 % |
| | `strong` | | 1300 мс, ×2.9, 70 % — быстро и заметно |
| `color` | `green` | ✅ | `--dsw-alias-state-success-primary` |
| | `yellow` | | `--dsw-alias-state-warn-primary` |
| | `blue` | | `--dsw-alias-brand-primary` |

Любое недопустимое значение (или битый JSON) откатывается к умолчанию по этому
полю — плагин не падает.

Как поменять (консоль DevTools в DSH):

```js
// жёлтый акцент и заметная пульсация, с пилюлей
localStorage.setItem("dsh.subagentIndicator", JSON.stringify({ mode: "both", intensity: "strong", color: "yellow" }));
// вернуть умолчание
localStorage.removeItem("dsh.subagentIndicator");
```

**После изменения — перезагрузка плагинов ⟳** (настройки читаются при
монтировании клиентской половины и при применении акцента; без перезагрузки
страницы новое значение не подхватится).

## 6. Архитектура кратко

| Половина | Файл | Роль |
|---|---|---|
| Host | `index.js` | пустой `apply()` — только валидная строка Loader |
| Client | `client.js` | тег `<style>`, словари, место в слоте `conversation.session.header.actions` (id `subagent-indicator`, order 20 — сразу после встроенного чипа с order 10) |

Почему так:

- **не рисуем второй чип**: встроенный принадлежит пакету
  `@deepseek-ai/dsh-client-ui-subagent`, который мы не контролируем; дубль в
  шапке сбивал бы с толку. Перекраска существующего — минимальное вмешательство;
- **состояние берётся из проекций**: `useSessions(state => state.projectionsBySession)`
  → `values.subagentCatalog` текущей сессии, плюс `useSessionStatus` (живая карта
  `id → {running}`) и `state.byId` (суммарии сессий). Субагент считается
  работающим, если `running === true` в живом статусе **или** в суммарии;
- **надёжный сигнал — свой атрибут** `html[data-dsw-subind]`, а не хешированные
  классы CSS-модуля хоста: имена классов меняются между сборками DSH, а атрибут
  наш;
- **цвета — только токены** `--dsw-alias-*`; ни одного hex/rgb/hsl в стилях;
- **место в шапке занимается в любом режиме**: даже `glow`, который не рисует
  узел, нужен, потому что именно он публикует `data-dsw-subind*` и переменные
  интенсивности.

Состояние: на диске ничего. Настройки — `localStorage`; всё остальное —
производные от проекций, пересчитываются на каждом рендере; при размонтировании
атрибуты и переменные снимаются.

## 7. Ограничения и типичные ошибки

- **`prefers-reduced-motion: reduce`.** Кольцо не анимируется, точка пилюли не
  мигает, но цвет и статичное кольцо остаются: состояние обязано быть видимым без
  движения. Если хочется убрать и цвет — это противоречит смыслу плагина, проще
  снять его.
- **Хешированные классы хоста.** Перекраска опирается на
  `button[aria-haspopup="tree"][class*="_trigger"]` и `[class*="_activitySlot"]`.
  Если DSH сменит разметку чипа, подсветка тихо перестанет работать — тесты
  поймают это только при обновлении ожидаемых строк в `test/run-tests.mjs`.
  Атрибутный путь (`html[data-dsw-subind="running"] button[aria-haspopup="tree"]`)
  останется рабочим дольше.
- **Пилюля только при работе.** В простое её нет — это осознанно: счётчик в покое
  ничего не сообщает.
- **Настройки кэшируются на монтирование.** Поменяли `localStorage` — нужен ⟳
  (или перезагрузка страницы), иначе старые значения останутся до перемонтирования.
- **Пилюля занимает место в полосе действий шапки.** Режим `glow` (по умолчанию)
  геометрию не меняет вовсе — если важна компактность, оставайтесь на нём.
- **Токены темы зависят от сборки.** Используются только опубликованные алиасы:
  `--dsw-alias-state-success-primary`, `--dsw-alias-state-warn-primary`,
  `--dsw-alias-brand-primary`, `--dsw-alias-label-secondary` и радиус
  `--dsw-radius-sm`. Если сборка перестанет публиковать какой-то из них, цвет
  молча не применится — это ловится тестом «каждый алиас опубликован».
- **Язык.** В сборке нет `ru`, интерфейс отвечает как `en`, поэтому русские
  подписи лежат в `DICTIONARIES.en`; английские сохранены и включаются заменой
  `en: RUSSIAN` на `en: ENGLISH`. В `glow` текста нет вообще — там только стили.
- **Нет субагентов в сессии** — нет и индикации: подсвечивать нечего.

## 8. Тесты

```powershell
node test/run-tests.mjs
```

**19 сторожевых тестов** (свой мини-harness: заглушка `__ModuleLoader__`,
мини-React и минимальный DOM, без внешних зависимостей). Покрыто:

- форма бандла: id `@local/dsh-subagent-indicator`, `inject = ["slots","locale"]`;
- ровно один тег `<style>` с `data-plugin-css`;
- словари для `en`/`ru`/`zh` и русская формулировка;
- `glow` занимает место в слоте, но не добавляет DOM-узлов;
- `pill` регистрирует место с `order > 10` (после встроенного чипа);
- селекторы под реальную разметку чипа и переменную акцента;
- наличие `@keyframes dshSubIndPulse` и привязка к точке;
- кольцо на собственном атрибуте `html[data-dsw-subind="running"]`;
- `prefers-reduced-motion` гасит анимацию, но не цвет;
- отсутствие хардкод-цветов и использование только опубликованных алиасов;
- цвет по умолчанию зелёный и переключение на жёлтый/синий (в `glow` тоже);
- `running` публикует состояние и числа на `<html>`, `idle` — нули;
- снятие атрибутов при размонтировании;
- пилюля: класс, русская подпись, единственное/множественное число, применение
  пресета интенсивности;
- устойчивость `catalogState` к отсутствующим проекциям и `readSettings` к мусору.

Вспомогательные скрипты (не тесты, для ревью):

```powershell
node test/build-preview.mjs [<файл.html>]   # статичное превью «до/после» в обеих темах
node test/dump-css.mjs                      # печатает стили плагина построчно и проверяет баланс скобок
```

Без аргумента `build-preview.mjs` пишет в
`%TEMP%\dsh-subagent-indicator-preview.html` и не трогает одноимённый файл в
репозитории; путь можно передать аргументом.
