# История изменений — Холст (`@local/dsh-canvas`)

## 1.0.0 — 06.11.2026

### Добавлено

- Вкладка **«Холст»** в правом доке (`keepMounted`) и кнопка открытия `canvas-open` в шапке сессии.
- Документ из блоков закрытого типа (`h1`, `h2`, `h3`, `p`, `li`, `quote`, `code`) с rich text
  только из spans `{t, b?, i?}`; плоские офсеты для комментариев.
- Восемь инструментов модели: `canvas_write`, `canvas_replace`, `canvas_set_title`, `canvas_clear`,
  `canvas_read`, `canvas_comments`, `canvas_apply`, `canvas_apply_edits`.
- Восемь маршрутов панели: документ, новый документ, комментарии, подготовка, pending, коммит,
  отмена, экспорт; единое тело ошибки `{code, hint}`.
- Комментарии к фрагментам одного абзаца: подсветка, рейл с сортировкой по позиции в документе,
  счётчик «N открытых» в заголовке вкладки, 500 комментариев с виртуализацией списка.
- Живая печать: `min(20 мс, 2500 / N)` на символ, при `N > 1200` — сразу; поллинг 500 мс во время
  записи и 3 с в покое, остановка на скрытой вкладке.
- Ручная правка абзацев: `contenteditable` на блоке, сохранение по blur и по паузе 400 мс,
  `If-Match`, баннер «Документ изменён — обновите…» вместо перезаписи.
- Перепривязка якорей: точный поиск, нормализованный, приблизительный (≥ 70 % слов), `orphaned` с
  причиной; ручная перепривязка осиротевшего комментария.
- Handshake применения: подготовка, возбуждение агента через `inject` + `followup`, пакеты,
  pending-набор, обзор «было → стало», коммит только человеком, отмена байт в байт.
- Стилевой паспорт документа и детектор дрейфа (новое эмодзи, рост больше 2,5×).
- «Процитировать в чате»: вставка `> «фрагмент»` + `(холст, абзац N)` с фолбэком в буфер обмена.
- Экспорт автономного HTML одной страницей (экранирование `& < > " '`, комментарии сносками по
  выбору).
- Хранение в профиле: атомарная запись, дебаунс 400 мс, история из 20 операций.

### Изменено

- Путь профиля берётся из `DSH_PROFILE_DIR`; жёстких личных путей нет.
- **Интерфейс полностью русский**: подписи, подсказки, ошибки, результаты инструментов и
  экспортируемый HTML — по-русски независимо от языка DSH; оставлен только `locale/ru.json`.
  Английские описания инструментов адресованы модели и остаются как требует спецификация.

### Исправлено

- Гонка «правка против поллинга»: ответ с версией не больше локальной игнорируется, поэтому
  сохранённый абзац не откатывается к прежнему тексту.
- **«Применить все» больше не валит ход.** Сообщение пробуждения несло `source.kind = "plugin"`,
  а формат журнала сессии v4 отвергает эту устаревшую обёртку (`format v4 message requires a
  producer-owned source kind`), и весь ход падал. Теперь вид производителя — `canvas`; сторож-тест
  26 проверяет и вид, и пару `inject` + `followup`.

### Ограничения

- **Word (.docx) не входит в 1.0.0** — вынесен в 1.1.
- **Своего PDF нет**: кнопка «PDF» экспортирует HTML и подсказывает «Печать → Сохранить как PDF».
- Выделение только внутри одного абзаца; межблочное выделение — вне области.
- Один активный документ на профиль; прежний уходит в архив (файл остаётся на диске).
- Документ до 200 000 знаков, `canvas_write` до 20 000, цитата до 2 000 — отказ, не обрезка.
- Текст документа уходит в модель при применении комментариев (см. README, «Приватность»).
