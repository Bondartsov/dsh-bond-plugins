# Холст (`@local/dsh-canvas`)

Документ внутри DeepSeek Harness: ассистент пишет текст на холсте, человек выделяет фрагменты и
оставляет к ним комментарии. Кнопка **«Применить все»** меняет **только прокомментированные
фрагменты** — остальной текст документа остаётся байт-в-байт.

Это не чат и не файл на диске, который надо открывать отдельно: холст живёт во вкладке правого
дока рядом с беседой, переживает перезапуск DSH и хранится в профиле.

**Язык интерфейса — только русский.** Все подписи, кнопки, подсказки, ошибки, результаты
инструментов и экспортируемый HTML — по-русски, независимо от языка интерфейса DSH. Английскими
остаются только описания инструментов для модели (требование спецификации) и коды ошибок —
это протокол, а не текст для человека.

## Как пользоваться

1. Откройте беседу и нажмите **«Холст»** в шапке сессии (или вкладку «Холст» в правом доке).
2. Попросите ассистента написать документ: «напиши коммерческое предложение на холсте». Текст
   появляется на холсте построчно — не мгновенно и не через минуту.
3. Выделите фрагмент **внутри одного абзаца** и нажмите **«Прокомментировать»**, затем напишите
   заметку — что именно изменить.
4. Повторите для остальных фрагментов. Счётчик в заголовке вкладки показывает, сколько открыто.
5. Нажмите **«Применить все»**. Ассистент получит пакеты комментариев и вернёт по одной правке на
   комментарий; в панели появится обзор **«было → стало»** с галочками.
6. Снимите галочки с правок, которые не нужны, и нажмите **«Применить выбранные»**. Коммит один и
   атомарный: либо применяются все выбранные правки, либо документ не меняется.
7. Передумали — **«Отменить применение»** вернёт документ к состоянию до коммита и снова откроет
   комментарии.

### Что ещё умеет панель

| Действие | Что делает |
|---|---|
| «В чат» | вставляет в композер `> «фрагмент»` и строку `(холст, абзац N)`, курсор остаётся ниже |
| «Новый документ» | архивирует текущий (файл остаётся на диске) и создаёт пустой |
| «Экспорт HTML» | сохраняет автономную страницу в `products/` рабочей папки; галочка «включить комментарии» добавляет их сносками |
| «PDF» | экспортирует HTML и подсказывает «Печать → Сохранить как PDF» |
| «Перепривязать» | у потерявшего якорь комментария: выделите новый фрагмент и нажмите «Привязать сюда» |
| «Решён вручную» | закрывает комментарий без применения правки |

### Ручная правка

Любой абзац можно править прямо на холсте. Правка сохраняется, когда вы уходите из абзаца или
делаете паузу 400 мс. Вставка из буфера вставляется **только как обычный текст** — разметка
источника отбрасывается, полужирный и курсив берутся из текущего состояния выделения (Ctrl+B,
Ctrl+I).

Если документ успели изменить в другом месте, панель не перезапишет абзац: появится строка
«Документ изменён — обновите, чтобы не потерять правки» и кнопка «Обновить».

## Ограничения версии 1.0.0

- **Word (.docx) — в версии 1.1.** Кнопки «Word» в 1.0.0 нет: писатель docx — отдельный крупный
  модуль, и он вынесен из первой поставки.
- **Своего PDF нет.** Кнопка «PDF» открывает экспортированный HTML с подсказкой про печать:
  корректная кириллица в PDF требует встраивания шрифта, а это уже отдельная задача.
- **Выделение — только внутри одного абзаца.** Попытка выделить два абзаца показывает подсказку
  «в этой версии — по одному абзацу».
- **Один активный документ на профиль.** «Новый документ» архивирует предыдущий; файл остаётся на
  диске, но из интерфейса уходит.
- **Документ до 200 000 знаков**, один вызов `canvas_write` — до 20 000, цитата — до 2 000.
  Превышение — отказ с кодом, а не обрезка.
- **Комментариев до 500** на документ; список в рейле виртуализируется.

## Приватность

**При применении комментариев текст документа уходит в модель.** Host формирует пакеты: цитата,
абзац целиком, предыдущий и следующий абзацы, стилевой паспорт документа. Эти данные попадают в
запрос к выбранной модели вместе с обычной беседой. Экспорт HTML и работа панели в модель ничего
не отправляют; запись в документ инициирует только человек.

## Установка

```powershell
cd C:\Users\<вы>\dsh-plugins
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -Only "@local/dsh-canvas"
```

Затем **полностью перезапустите DSH**: плагин добавляет и Host-часть (инструменты, маршруты), и
клиентский бандл. Перезагрузка плагинов ⟳ для первого запуска не подходит — новый клиентский бандл
появляется только после перезапуска приложения.

## Где лежат данные

| Что | Где |
|---|---|
| Документы | `%USERPROFILE%\.dsh\profiles\desktop\canvas\doc-<N>.json` |
| История (20 операций) | `...\canvas\doc-<N>.history.json` |
| Указатель активного документа | `...\canvas\index.json` |
| Экспорт HTML | `products\холст-doc-<N>-<ДД.ММ.ГГГГ>-<ЧЧММСС>.html` в рабочей папке |

Путь профиля берётся из `DSH_PROFILE_DIR`; личных путей в коде нет.
