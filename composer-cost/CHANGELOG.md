# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — semver.

## 1.0.0 — 31.10.2026

Первый публичный релиз в составе репозитория `dsh-bond-plugins`.

### Добавлено

- Клиентская ячейка `cost` в слоте `conversation.composer.dock` (order 2): оценка
  расхода всего лога текущей сессии в рублях с именем модели в ярлыке.
- Клиентская ячейка `cost-total` (order 3): расход за сегодня и, по наведению,
  за день и неделю с разбивкой по маршрутам моделей.
- Панель по наведению для сессии: четыре счётчика (`Вход без кэша`, `Чтение из
  кэша`, `Запись в кэш`, `Выход`) с токенами, ставкой и рублями, строка `Маршрут`
  и сноска о том, что весь лог считается по тарифу текущей модели.
- Таблица тарифов `TARIFFS` для двух маршрутов Polza.AI — `deepseek/deepseek-v4.1-flash-1017`
  и `minimax/minimax-m3.1-flash` (снято 28.10.2026 из `GET /models/{model}` →
  `top_provider.pricing`).
- Определение маршрута по `modelSelection.lastUsed` → `next` → последнему шагу
  ассистента → `DEFAULT_ROUTE`.
- Реестр страницы в `localStorage["dshCost.ledger.v1"]` на 30 дней: агрегация
  «день → маршрут», окна «день» и «неделя», суммы по всем открывавшимся сессиям.
- Явное состояние «нет тарифа»: `— ₽ · <модель>` в ярлыке и «нет тарифа» в панели
  итога; нулевой расход скрывает ячейку вместо `0,00 ₽`.
- Русские подписи в наборе `en` (в сборке DSH нет языкового пакета `ru`);
  английский вариант сохранён и включается одной строкой.
- Русский денежный формат: узкий неразрывный пробел в тысячах, запятая перед
  копейками, `<0,01` для сумм меньше копейки; даты — `ДД.ММ.ГГГГ`.

### Ограничения релиза

- Итог за день/неделю считает только сессии, открывавшиеся в этом окне
  (`localStorage` страницы), и не синхронизируется между профилями.
- Тарифы статичны: новый маршрут требует правки `TARIFFS` и перезагрузки плагинов.
- Весь лог сессии оценивается по тарифу её текущей модели — провенанса токенов по
  моделям в `tokenUsage` нет.
- Собственных тестов нет; проверка — ручная (см. README, §8).
