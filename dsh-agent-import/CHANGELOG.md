# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — semver.

## 1.0.0 — 31.10.2026

Первый публичный релиз в составе репозитория `dsh-bond-plugins`. Пакет
публикуется как **движок** импорта: собственной панели у него больше нет.

### Добавлено

- Адаптеры шести источников (Claude Code, Codex, ZCode CLI, ZCode v2, KiloCode,
  OpenCode) с единым контрактом `status` / `listSessions` / `readSession`;
  чужие хранилища только читаются.
- Синтезатор валидного V4-лога (`turn/start` → … → `turn/end`) с плотным `seq`,
  нумерацией `turn`/`step`, обязательным системным заголовком и парностью
  `tool/call` ↔ `tool/result`.
- Запись через `sessionPersistence` (`create` → `append` → `flush` → `close`) с
  обязательным холодным перечитыванием и проверкой V4-инвариантов.
- Детерминированный идентификатор сессии `session-<uuid из sha256(source, foreignId)>`
  — повторный импорт возвращает `already-imported` вместо дубля.
- Инструмент модели `agent_import` с действиями `scan`, `search`, `import`,
  `update`, `reimport`, `verify`, `continue`, `ledger`, `assets`, `mcp_plan`,
  `copy_skills`, `ui`; ответ `{action, text, data}` с готовым русским отчётом.
- 13 HTTP-маршрутов `/agent-import/*` с same-origin гардом, ограничением тела
  запроса и единым форматом ошибок (`400/403/405/409/500`).
- Импорт пачками (`/import-batch`, до 50 элементов) с независимым результатом по
  каждому элементу и сводкой `{total, imported, already, failed}`.
- Дозапись хвоста (`update`) с отметкой объёма и отпечатком начала истории в
  ledger; различение случаев `up-to-date`, `diverged`, `needs-reimport`, `busy`;
  пересборка копии с архивацией прежней вместо удаления.
- Субагентные (порождённые) сессии: отдельные счётчики, скрытие по умолчанию,
  `includeChildren` для раскрытия и `includeSubagents` для добавления контекста
  детей в родительскую копию размеченными appendix-ходами.
- Инвентарь ассетов: скилы (копирование в `~/.dsh/skills`), плагины (только
  перечисление), MCP-серверы (предложение `- insert:`-фрагментом, профиль не
  правится), конфиги (только наличие и размер).
- Проверка продолжения (`continue`): резюм импортированной сессии и один промпт с
  ожиданием хода в том же логе.
- Диагностика `ui`: попал ли клиентский бандл в манифест страницы, и что нужно —
  перезагрузка страницы или полный перезапуск DSH.
- 62 теста в шести файлах: синтез V4 (24), импорт и ledger (7), форма плагина и
  маршруты (7), адаптеры источников (8), субагентные сессии (8), обновление и
  переимпорт (8).

### Изменено

- Клиентская половина оставлена только как страница `main` (ключ
  `agent-import`) — цель deep-link. Строка в левой панели, кнопка в шапке беседы
  и вкладка в правом доке сняты: вход в миграцию один, через вкладку «Миграция»
  пакета `dsh-migrate`, чтобы не было двух импортёров.

### Известные расхождения

- `includeSubagents` читается в `execute`, но не объявлен в схеме параметров
  инструмента: через маршруты поле доступно, через инструмент — нет.
- Инструментальное действие `reimport` не передаёт `confirm`, который требует
  одноимённый маршрут.
- `verify` всегда возвращает `readable: true`; фактический признак успеха —
  отсутствие исключения.
- `package.json` объявляет три клиентских `inject`, хотя после снятия панели
  достаточно одного; расхождение безвредно и код документацией не менялся.

### Ограничения релиза

- Изображения из чужой истории заменяются текстовым плейсхолдером.
- Вызов инструмента без записанного результата отбрасывается (счётчики в отчёте).
- ZCode v2 хранит только текст — потеря инструментов сообщается.
- Отсутствующий на машине проект сессии заменяется рабочим каталогом DSH по
  умолчанию, исходный путь остаётся в ledger и предупреждениях.
- Рантайм чужих плагинов не переносится: только их скилы и MCP-серверы.
