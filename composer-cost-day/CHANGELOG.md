# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — semver.

## 1.0.0 — 31.10.2026

Первый публичный релиз в составе репозитория `dsh-bond-plugins`.

### Добавлено

- Подписка-наблюдатель на waterfall `llm/stream`: чанк `type: "usage"` добавляет
  провайдерский расход в реестр, не меняя поток и не влияя на вызов модели.
- Реестр «день → маршрут `provider/model` → четыре счётчика токенов»
  (`uncached`, `cacheRead`, `cacheWrite`, `output`) в
  `<DSH_HOME>/storages/composer-cost/daily.json`.
- Атомарная запись (`daily.json.tmp` → `rename`), склейка всплесков 1500 мс,
  финальный сброс при выгрузке плагина, хранение 60 дней с очисткой старых дней.
- Маршрут `GET /composer-cost/today?token=<UUID процесса>`, отдающий только
  сегодняшнюю запись; `403` без токена и `405` для остальных методов.
- Вставка токена страницы `window.__DSH_COST_TOKEN__` в `index.html` через
  `webServer.tapIndex` — читать реестр может только страница, отданная этим Host.
- Устойчивость к отсутствующему или испорченному файлу реестра: старт с пустого
  реестра без исключения; ошибка записи только логируется.
- Объявленная зависимость `inject = ["webServer"]`, чтобы на холодном старте
  маршрут регистрировался после публикации службы.

### Ограничения релиза

- Счёт начинается с момента запуска пакета: вызовы до установки не восстанавливаются.
- Собственного интерфейса нет; текущая клиентская ячейка `cost-total` читает
  `localStorage` страницы, а не этот маршрут (причина — origin `dsh-app://app`).
- Рубли не считаются: пакет отдаёт токены, тарифы остаются в `@local/composer-cost`.
- Собственных тестов нет; проверка — ручная (см. README, §8).
